# Chat_Bot_v1
AI enabled chatbot system designed to interact with users. The goal is to provide real-time and immediate responses to costumers and make them have conversations about their data. 

Using Amazon Bedrocks models for AI, Amazon Lex for the chatbot and S3 for document storage.
